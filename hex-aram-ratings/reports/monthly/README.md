# 月报

按 `YYYY-MM/` 建立子目录。使用[评分标准 HD-RATING-2.1](../../docs/海斗日评与月评评分标准.md)计算本月有效单局综合分的算术平均，不直接平均每日分。

每份月报注明规则版本、冻结参考快照、游戏版本、有效场数、实际参赛场数、评分覆盖率、参与游戏日与共同对局数。纳入六人名单中至少三人同场的组排，仅为名单内实际参赛者计分，路人参与团队占比分母及五人同场环境系数。中位数、较低四分位表现、出勤和胜负独立展示，不额外加扣月分。跨版本分段展示；小样本和缺失数据须明确标记，名次附参数稳定性检查。

每份月报附按月分从高到低的一图流，逐一写出队员所选英雄的静态定位分布、实际场数与基于可复核分项的点评。分数排序要注明参赛对局是否一致，不能把不同场次的月分次序称为同条件实力排名。

本月未结束或对局尚未核完时仅生成标注已收集日期的阶段月评；完整月度成绩另在数据核对完毕后发布。当前 [2026-09 阶段月评](2026-09/)仅纳入 23、24、26、27 日，不包含只有历史分项试算的 22 日。
