# 海斗日评与月评

六人轮换组排的海克斯大乱斗战绩归档。日评、月评使用北京时间 **04:00（含）至次日 04:00（不含）** 的游戏日，按对局开始时刻归档。

> 当前规则为 **HD-RATING-2.1（试行）**：输出与承伤各按“60% 经同场五人中位数调整的同英雄发挥＋40% 本场团队负担”计分，再结合英雄特点、参团和死亡成本形成单局分；日分、月分按有效单局等权平均。六人名单中至少三人同场的组排，名单内队员计分，路人参与团队占比分母和同场调整。具体算法见[评分标准](docs/海斗日评与月评评分标准.md)，修订原因见[更新记录](docs/更新记录.md)。

### 2026-09-22 数据说明

这一批保留原版本的历史分项试算，尚未按 v2.1 重算。有 8 场上传对局和 8 张截图，六人名单中 4 人有记录，其中**按当时旧版五人固定队范围可计算完整综合分的对局为 0 场**。日报用于复盘，展示的 O／K／V 是分项参考试算；没有个人综合排名。部分截图缺少精确开局时间，游戏日归属依上传批次暂定，取得完整时间后应复核。

日报 PNG 和核对明细 ZIP 尚待补传；已入库的原始截图见上表。

### 2026-09-23、24、26、27 数据说明

四个日期目录合计 36 张原始截图、180 行己方选手战绩，其中 160 条来自六人名单队员，已按 HD-RATING-2.1 重新出分（旧版 CSV 和日报仍保留）。逐场包含六人名单中的 3～5 人；路人的 20 行用于团队占比分母和五人同场环境调整，但不进入个人榜。截图中的 KDA 已重新逐行核对，五人击杀之和与己方总击杀逐场一致；原值仅有“万／k”精度，不宣称更精确。国服 26.19 的上线公告与 ARAMKit v16.19 版本页用于版本匹配；公开参考冻结于 9 月 28 日。跨站“自我减免”与“自我减伤”仍待口径核实，缺少精确钟点的截图按用户给出的游戏日目录归属。

日分为各人实际参赛场次的均分。每日一图流按这个数字排序并逐人点评，但参与者比赛集合不一致时，序号只表示已收集对局的均分大小；9 月 27 日 Let325544 的 53.3 分来自两场，报告另列这两场的五人共同对局比较。现有阶段月评同样按已收集的四个游戏日中的全部有效单局等权汇总，不作为完整 9 月成绩。

## 后续更新约定

1. 原截图放入 `screenshots/YYYY-MM-DD/`，保留文件来源和开局时间。
2. 每日日报放入 `reports/daily/YYYY-MM-DD/`，月报放入 `reports/monthly/YYYY-MM/`。
3. 每次出分都注明规则版本、样本范围和缺失项；口径修订记录在 `docs/更新记录.md`。
4. 公开截图前先检查并处理战绩无关的聊天、联系方式等信息。
