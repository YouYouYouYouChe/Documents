# 海斗日评与月评评分标准

**规则编号：HD-RATING-2.2**

快速了解规则可先看[评分说明一图流（2.2）](海斗评分说明一图流_HD-RATING-2.2.png)；本页提供完整公式、数据要求和适用边界。

**状态：固定队战绩表现评分，试行**

**游戏日：北京时间 04:00（含）至次日 04:00（不含），按开局时间归属。**

## 1. 这份评分评价什么

本标准用于六人轮换组排的海克斯大乱斗复盘。当前执行版本为 **HD-RATING-2.2**。它综合评价赛后可见的英雄发挥、团队负担、参团表现和死亡成本，可以计算适用对局的单局分、日分和月分；不要求队员自行建立全服数据库。

评分采用第三方公开英雄数据作为参考，将本场五名队友各自的同英雄倍率进行同场环境调整，同时使用本局的团队占比。输出和承伤各由 **60% 同英雄发挥分＋40% 本场负担分**组成，再结合英雄特点分配权重。综合分中，战斗表现占 70%，参团占 20%，死亡项占 10%。

分数是按统一规则计算的战绩表现指标，不是官方评分、玩家百分位或对胜负的真实贡献率。权重和换算曲线是公开的模型设计选择，尚未经胜负标签或专家复盘验证。数值越高表示在这套规则下表现越突出，不等于每项行为都更有价值。

适用队员：东冬咚胨#49567、Let325544#73173、丨云胡丨不喜丨#24728、划水打野#51907、Premieresape丶Li#45121、羊村头目慢羊羊#24440。更名时保留完整游戏 ID 与别名对应关系。

## 2. 比赛范围与所需数据

本榜纳入已确认一起组排、且己方至少三人来自上述六人名单的比赛；六人名单中实际参赛者各算一次个人单局分。己方名单外玩家不进入个人榜，也不参与月日均分，但其输出、真实承伤等仍须进入本场己方五人团队占比的分母与环境调整的中位数。三人、四人和五人组排统一展示，同时逐场标注熟人人数；单排和不足三名熟人的对局另列，不混入本榜。六人轮换时，报告需列出每人参赛场数与共同对局数。

对局去重，剔除重开、时长不超过 4 分钟及无法识别模式的记录，并保留原因。败局、低输出和掉线不能仅因成绩差而被删除。字段缺失的比赛保留在参赛记录中，标记未完整评分，不当成零分。

| 字段 | 用途 |
| --- | --- |
| 对局 ID、模式、版本、开局时间、时长、胜负 | 对局识别、日期归档及参考版本匹配 |
| 己方五人完整游戏 ID、英雄 | 固定队范围、同英雄比较和团队分母 |
| 个人击杀、助攻、死亡，己方总击杀 | 参团与死亡项 |
| 个人及己方五人的对英雄伤害、真实承伤 | 分均指标和同场占比 |
| 组排人数、职责、出装和海克斯（可获得时） | 解释单核、单前排和非主流玩法 |
| 治疗、护盾、控制、经济（可获得时） | 补充展示；本版不另加权计分 |

截图已直接显示同口径占比或参团率时，可以使用显示值并标明取整精度；分均指标仍须有个人原始总量和时长，不能只凭百分比倒推出总量。只有“8.7 万”等显示值时保留该精度。缺少时间、版本等信息要明确标记，不能编造。

### 真实承伤的定义

> **真实承伤＝承受伤害＋自我减伤。**

这是 HexData 桌面端提示的定义。已提供真实承伤时直接取值，不能重复加上承伤或减伤。若只有承受伤害而没有自我减伤，只能标为“承伤”，不能当作真实承伤参与本版公式。

ARAMKit 的“自我减免”暂按与桌面端“自我减伤”同义的字段用于试算。两站是否完全同口径尚未核实，所有采用这一跨站映射的结果标注 **“跨站承伤口径待核实”**。若发现定义、伤害来源范围或统计对象不同，应停止混用、保存原值并统一重算受影响的结果。

## 3. 英雄参考表

个人战绩可以来自 HexData 桌面端或原始截图；英雄参考优先统一采用 [ARAMKit](https://aramkit.com/zh-CN) 同模式、同版本、同分段范围的公开英雄数据。默认使用全分段，不混入高分段表。参考来源是第三方公开样本，不宣称覆盖全服。

每份参考快照保存来源链接、抓取日期、游戏版本、分段范围、可见样本量（未提供则写“未提供”）、字段定义和英雄覆盖列表。对该版本使用同一份冻结快照，网站日后更新不能悄悄改变已发布分数。当前版本参考不能冒充历史版本参考；不能匹配时只展示原始战绩，或另列并明确标注跨版本参考试算，不并入同口径榜单。

对英雄 h，从同一统计口径取平均对英雄伤害、平均承受伤害、平均自我减免、平均参团率、平均死亡次数和平均时长，计算：

| 符号 | 计算方法 |
| --- | --- |
| bO,h | 平均对英雄伤害 ÷ 平均时长（分钟） |
| bT,h | （平均承受伤害＋平均自我减免）÷ 平均时长（分钟） |
| bK,h | 页面直接公布的平均参团率，以小数表示 |
| bV,h | 平均死亡次数 ÷ 平均时长（分钟） |

“平均总量÷平均时长”是聚合数据推导的参考速率；当各项来自同一批对局时，相当于按时长加权的逐局速率，**不等于逐局分均值的简单平均**。同理，不用平均击杀、平均助攻拼出网站没有提供的平均参团率。

所有参考分母须为正。字段缺失、版本不匹配或统计口径冲突时，不填造默认参考。

## 4. 同英雄发挥分

设本局时长为 t 分钟，个人对英雄伤害为 d，真实承伤为 a，击杀为 k，助攻为 q，死亡为 v，己方总击杀为 K。

```text
个人分均输出 = d / t
个人分均真实承伤 = a / t
个人参团率 = (k + q) / K
个人死亡速率 = v / t

输出倍率 rO = (d / t) / bO,h
承伤倍率 rT = (a / t) / bT,h
参团倍率 rK = ((k + q) / K) / bK,h
```

己方总击杀为 0 时，参团率无从计算，不能记为 0 或默认平均值。只有个人击杀与助攻、没有己方总击杀或直接参团率时，同样不能计算这一项。

输出、承伤、参团倍率统一用以下函数换算：

$$
F(r)=\frac{100r}{1+r}
$$

| 相对参考的倍率 | 发挥分 F(r) |
| --- | ---: |
| 0 | 0.0 |
| 0.5 | 33.3 |
| 1.0 | 50.0 |
| 1.1 | 52.4 |
| 1.5 | 60.0 |
| 2.0 | 66.7 |
| 3.0 | 75.0 |

对参团项，50 分表示参团倍率等于英雄参考；对输出、承伤项，50 分表示经本场环境调整后的倍率为 1，不表示不及格，也不表示处于玩家第 50 百分位。换算后的玩家平均分未必恰好为 50。函数连续且奖励逐渐放缓，减少极端数值对总分的支配；这不是已经验证的贡献曲线。

分均数据和原始倍率展示原值；用于输出／承伤发挥分的是下一节的**调整后倍率**，参团倍率不做同场环境调整。分均量与相对参考倍率是同一信息的不同表达，不各加一次分。

## 5. 同场环境调整

有些对局会让己方多人同时比各自英雄的平常伤害高出很多。为了减轻这类比赛对单人输出分的抬升，在计算输出与承伤的发挥分之前，**分别**使用本局己方五人的原始倍率确定环境系数。五人包括名单外队友；不是拿五个原始伤害量直接比较。

```text
本场输出环境系数 eO = max(1, 五人原始输出倍率的中位数)
本场承伤环境系数 eT = max(1, 五人原始承伤倍率的中位数)
调整后输出倍率 rO* = 个人原始输出倍率 rO / eO
调整后承伤倍率 rT* = 个人原始承伤倍率 rT / eT
```

五个数的中位数是从小到大排第 3 个；`max(1, ·)` 表示如果中位数不足 1，环境系数取 1，不因全队倍率偏低而给个人加分。输出与承伤单独求系数，本场伤害偏高不自动影响承伤分。**只有五名队友的英雄、时长、输出总量、真实承伤总量，以及全部五名英雄适用的同版本参考均可用时，才计算这两个系数。** 无法完整计算时本局综合分留空，不拿已知三四人替代五人，也不填补路人数据。

例如五人原始输出倍率依次为 1.10、1.67、2.05、2.37、3.89，则 eO＝2.05；原始倍率 2.37 的队员调整为 2.37÷2.05≈1.16，输出发挥分约从 70.3 变为 53.7。这里只调整占输出分 60% 的发挥部分；输出占比仍按本场五人总量计算，其 40% 负担部分不变。承伤依同样方法分别计算。

**解释边界**：中位数偏高也可能来自全队真实打得好，而非异常比赛；这个方法会压低同局所有人的相应发挥倍率，对原本低于中位数者也有影响。它无法证明对手、伤害质量或每个人的实际贡献，也不会消除长局的成长效应。报告须同时列原始倍率、环境系数、调整后倍率和团队占比；与旧规则分数分开标注。中位数、下限 1 和原有权重都是公开的设计选择，没有胜负或人工复盘证据证明它们唯一正确。

## 6. 本场团队负担分

```text
输出占比 sO = 个人对英雄伤害 / 己方五人对英雄伤害之和
真实承伤占比 sT = 个人真实承伤 / 己方五人真实承伤之和
```

分母必须是本场己方五人的同口径数据，不能把五名英雄各自不同比赛的历史均值相加来代替。可以使用桌面端直接提供的同口径占比；若自行计算时五人数据不齐，则该占比留空。团队总量为 0 时，该项无从计算。

占比用小数表示，如 30% 填 0.30，使用：

$$
B(s)=\frac{100s}{s+0.20}
$$

| 队内占比 | 负担分 B(s) |
| --- | ---: |
| 0% | 0.0 |
| 10% | 33.3 |
| 20% | 50.0 |
| 30% | 60.0 |
| 40% | 66.7 |
| 50% | 71.4 |
| 100% | 83.3 |

0.20 是五人等分的数学参照，不是任何英雄的达标要求。高占比说明本场承担的这项工作量更多，不直接证明质量更高；队友表现较差也可能抬高个人占比。因此它只占对应项目的 40%，且高占比的额外奖励逐渐减少。

单核或单前排仅作为背景标记，不因此额外抬高发挥参考，也不自动给予补偿分。

## 7. 输出分、承伤分及英雄权重

$$
O=0.60F(r_O^*)+0.40B(s_O)
$$

$$
T=0.60F(r_T^*)+0.40B(s_T)
$$

下面是纯公式示例，假设两人的承伤发挥分都为 50，不代表任何队员的真实重算结果：

| 假设情况 | 承伤发挥分 | 真实承伤占比 | 合成承伤分 T |
| --- | ---: | ---: | ---: |
| 前排 | 50.0 | 47% | 58.1 |
| ADC | 50.0 | 16% | 47.8 |

输出、承伤在战斗分中的权重由外部英雄参考表计算。对同一冻结快照中 bO,h、bT,h 均完整且为正的英雄，分别计算输出速率中位数 MO 与承伤速率中位数 MT；偶数个值的中位数取中间两个的平均。保存完整参与列表与缺失列表，不随待评分玩家或本局阵容改变参考英雄集合。

```text
aO,h = bO,h / MO
aT,h = bT,h / MT
wO,h = aO,h / (aO,h + aT,h)
wT,h = aT,h / (aO,h + aT,h)
```

wO,h＋wT,h＝1。输出特点更明显的英雄侧重输出，承伤特点更明显的英雄侧重承伤。不能在赛后根据哪项数据更好看再更换权重。

这些权重体现公开样本中的英雄数据特点，不代表已经测得各项对胜利的重要性。非主流出装和特殊海克斯可能偏离英雄总体特点，报告须保留相关背景。

## 8. 综合单局分

参团分为 F(rK)。死亡项 V 的计算如下：

$$
V=100\times\frac{b_{V,h}}{v/t+b_{V,h}}
$$

在死亡参考速率为正时，零死亡得到 100；与同英雄参考一致得到 50；死亡速率为参考的两倍得到约 33.3。死亡项只占 10%，用于体现有限的死亡成本，不能据此判断某次死亡是失误还是合理换命。

综合分为：

$$
S=0.70\left(w_{O,h}O+w_{T,h}T\right)+0.20F(r_K)+0.10V
$$

| 综合分的信息组成 | 总权重 |
| --- | ---: |
| 输出与承伤的同英雄发挥（经同场环境调整） | 42% |
| 输出与承伤的本场团队负担 | 28% |
| 同英雄参团表现 | 20% |
| 同英雄死亡成本 | 10% |

70/20/10 与 60/40 是本模型统一采用的设计选择，不是第三方网站公布或统计证明的唯一正确权重。队伍胜负、击杀、助攻、KDA、总经济和伤害转化率可以展示，但不重复加分。**本公式不涵盖治疗、护盾与保护效果；明确承担保护职责的软辅局按下节单独处理。**

输入与中间结果保留原始精度，仅在展示时四舍五入到一位小数。任何必需项无从计算时，该局只展示完整分项，综合分留空；不填 0、不补成平均值，也不把缺失权重分配给其他项目。

## 9. 保护型软辅对局的适用范围

目前可取得的赛后数据不能可靠计算治疗、护盾、关键保护或控制的有效贡献。对可根据**英雄、本局截图与可见出装职责**明确判定为保护型软辅的队员，该局**不计算通用综合分，不纳入通用日均、月均和排序**；个人原始战绩、参团、输出、真实承伤以及历史原公式试算分仍保留，供单独复盘。旧版试算分必须明确标成旧规则结果，不得混进当前通用分。

只排除软辅队员的个人评分；**比赛仍保留，同场其余队员照常评分**。软辅队员和名单外队友均继续参与本场五人的团队占比分母与同场环境系数。不能因该人玩软辅就剔除全场，或仅用其余四人重算环境。

判定以**逐局、逐人**为单位：先核对英雄与截图，必要时结合出装；将决定、截图及理由记录在公开冻结清单，不能因单局计算分数高低而决定是否排除。英雄静态 `Support` 标签不等于本局是软辅；前排开团辅助、输出装赛娜等仍按原公式计分。出装或角色难以从现有证据判定时标明待核验，不凭低输出／低承伤自动剔除，也不冒充可靠的保护分。

本批四个完整游戏日冻结 [四条逐局排除记录](../repro/soft_support_exclusions_v2.2.json)：9 月 24 日 M05 卡尔玛（截图可见辅助取向出装）、M06 索拉卡；9 月 27 日 M05 烈娜塔、M07 悠米。9 月 23 日 M04 和 9 月 27 日 M06 赛娜截图呈输出取向，继续计分。新对局应在发布前按同一规则核验，并在清单增加逐局证据；不根据已出分数回头选择。

日月报均列出**实际参赛场数／纳入通用评分场数／软辅场数**。软辅局被排除是评分适用范围限制，**不属于原始数据缺失**；因此“纳入率”应与数据采集完整率分别说明。如某人本期全是软辅局，通用均分与序位留空，只展示场数和可核实的原始表现。该方法避免对保护职责的明确压分，但不能据此给保护型辅助排名。

## 10. 名次稳定性检查

主分按第 8 节发布，同时为所有人统一计算九组辅助方案。输出与承伤内部的 60% 同场调整后发挥＋40% 负担保持不变；九组辅助方案使用同一组 eO、eT：

- 战斗总权重 c 取 0.60、0.70、0.80；死亡固定 0.10，参团取 0.90－c。
- 输出相对承伤的权重倍率 λ 取 0.8、1.0、1.2，然后重新归一化。

```text
调整后 wO = λ × wO,h / (λ × wO,h + wT,h)
调整后 wT = wT,h / (λ × wO,h + wT,h)
辅助分 = c × (调整后 wO × O + 调整后 wT × T)
         + (0.90 - c) × F(rK) + 0.10 × V
```

三种 c 与三种 λ 组合成九组，其中包含主方案。日月辅助分使用与主分完全相同的对局集合，再逐场等权汇总；不能为某个人选择最有利的参数。

只有比较对象参加完全相同的比赛时，才对九组辅助方案展示名次变化范围。两人在九组中均保持同一先后，说明在这组参数范围内排序较稳定；出现先后翻转或无法区分的相等结果，则标记“接近，先后不稳定”。这个检查不验证指标本身的正确性，不能修复样本场次、时长、阵容或字段口径偏差。名次变化范围不是统计置信区间。

## 11. 日评与月评

游戏日按北京时间 04:00（含）至次日 04:00（不含）内的开局时间归属。例如 9 月 23 日 03:59 开始属于 9 月 22 日，04:00 开始属于 9 月 23 日。跨月同理：10 月 1 日 03:59 开始归入 9 月 30 日游戏日及 9 月月报。

**日分＝当天纳入通用评分的单局综合分的算术平均。** 每场等权，不按时长、伤害量或胜负加权；标题和图中称“可评分对局均分”。

**月分＝本月全部纳入通用评分的单局综合分的算术平均。** 不直接平均每日分，避免只打一场的日子和打十场的日子获得相同月度权重。软辅个人局只记录参与，不进入平均分分母。

样本少也可以显示参考分，但必须同时列出纳入通用评分场数、实际参赛场数、软辅场数、数据采集完整率及参与游戏日。没有适用综合分时留空。缺失比赛仍计入实际参赛场数；**纳入率＝纳入通用评分场数÷实际参赛场数**，软辅局数据可能完整，纳入率不得标作数据完整率。不能因少数场次得分高就宣称长期水平高。

**日分是个人当天纳入通用评分场次的均分。** 日报和一图流统一按这个数字由高到低给出**分数序位**，同时紧挨着显示纳入场数／实际场数及软辅场数。只有参与者的**纳入评分**比赛集合完全相同，序位才可解释为同场次表现名次；否则序位仅表示各自样本的均分大小，不能称作“全天实力第几名”。需要评价两个人的相对表现时，另取双方共同参与且双方均纳入评分的比赛计算“共同对局均分”，并列明共同场数；这个均分不替代各自日分。若共同对局只有一两场，只能解释这几场的表现，不能概括当天长时间参赛者的全部表现。

**每份完整日报和月报都生成一张分数总结一图流。** 一图流按分数序位展示有适用评分的队员，列出分数、纳入／实际场数、软辅场数、主要英雄定位、代表英雄及逐人点评。英雄分布按实际参加的局数统计；综合分、最高最低分和分项均只使用纳入评分的对局；软辅局不当成该人低分局。不依据“射手必须打多少伤害”或“坦克必须承受多少百分比”另设门槛，不给点评额外加扣分。若有人仅参与软辅局，一图流另列“通用分缺席”，不赋予虚构名次。

英雄定位采用同版本 Riot Data Dragon `champion.json` 的 `tags` 静态标签：`Tank`／`Fighter`／`Marksman`／`Mage`／`Assassin`／`Support` 对应前排／战士／射手／法师／刺客／辅助。分布统计采用每名英雄的第一个标签；代表英雄同时展示全部标签，以免把双定位抹去。标签只是英雄通常的分类，**不能从英雄标签推断该局实际出装、谁是唯一前排、是否发挥了辅助作用**；没有装备或海克斯记录时不作此类断言。定位冻结表见[同版本英雄定位快照](../references/riot_ddragon_16.19.1_英雄定位.json)。

月内尚未收齐或尚未结束时，只能生成写明**已收集日期**的“阶段月评／阶段均分”一图流，不能把它称作完整月榜。月度数据核对完整、游戏月结束后，才按全部适用单局生成正式月评图；9 月 22 日目前只有历史分项试算，不纳入 2.2 阶段均分。

日报和月报至少列出：

| 内容 | 展示要求 |
| --- | --- |
| 综合分及分项 | 主分、一位小数（图片可展示两位以区分接近分数）、主要分项、权重检查结果 |
| 样本范围 | 实际／纳入／软辅场数、纳入率、数据完整率、胜负、游戏日、组排范围、共同对局数 |
| 数据表现 | 分均输出、分均真实承伤、原始倍率、同场环境系数、调整后倍率、逐场团队占比、参团与死亡 |
| 英雄与职责 | 静态英雄定位、英雄分布；单核/多核、单前排/多前排、特殊玩法仅在有对局证据时补充 |
| 参考与限制 | 规则编号、参考快照、游戏版本、缺失项、跨站字段口径状态 |

稳定性另列中位数和第 25 百分位表现，不额外扣入月分。第 25 百分位按有效单局分从低到高排序，使用位置 1＋(n－1)×0.25 及相邻位置线性插值；一场时它等于该场分数，不提供额外稳定性证据。

个人全场统计与共同对局比较分开呈现。仅一两场时，单场明细比名次更有解释力。月报同样保留每人场数和参与日期，不给不同比赛集合的月度均分冠以“同条件实力名次”。

跨游戏版本按版本分段展示。不同评分规则下的分数不直接混合，统一按同一规则回算后才可合并；参考快照修订时保存旧结果并统一重算受影响范围。

## 12. 使用边界

### 对局时长

分均数据消除了单纯的时间累计，却不能消除等级、装备和海克斯成长。长局的每分钟输出或承伤可能更高，目前只有英雄总体聚合参考，无法可靠推导同英雄在各时长的曲线。

本版仍保留分均指标，结合五人中位数环境调整和团队占比，不虚构时长修正系数。环境中位数与占比同样受阵容、英雄成长曲线和队友表现影响，因此只能缓和部分偏差，不能宣称完成了时长校正。报告保留对局时长及其分布，优先结合相近时长或共同对局解释结果。

### 有效贡献与重复计分

赛后伤害总量无法区分关键输出与低价值消耗；真实承伤也无法区分保护队友与无效吃伤。死亡次数不能区分失误、换命与补装备时机。增加高度相关的指标不能自动提高公平性，本版不把输出、相对输出和伤害转化率重复奖励。

### 辅助与特殊玩法

治疗、护盾和控制补充了当前公式没有覆盖的职责信息。数据可得时展示，但本版没有给这些指标规定综合权重，不能临时增加分数或给不同玩家使用不同公式。明确的保护型辅助局按第 9 节暂不计通用分；这不说明它打得好或差。特殊出装也可能与英雄总体参考不匹配。

### 参考样本与可复核性

第三方公开样本不等于全服代表性样本。缺少逐局分布时，不能把本分数解释为全服排名或超过多少玩家。保存原始截图、转录值、计算明细、参考快照与缺失原因，使他人可以复算。
